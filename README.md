# Pahana Edu Bookshop

## Project Overview

A web-based bookshop management system for Pahana Edu bookshop in Colombo City. The system manages customer accounts, item inventory, and billing information.

## Core Requirements

### 1. User Authentication
- Username/password login
- Session management
- Logout functionality

### 2. Customer Management
- Add new customer accounts (account number, name, address, telephone)
- Edit existing customer information
- View customer details

### 3. Item Management
- Add new items (code, name, description, price, stock quantity)
- Update existing item information
- Delete items
- List all items

### 4. Billing System
- Calculate bills based on items purchased
- Generate printable receipts

### 5. Help Section
- Basic usage guidelines
- FAQ

### 6. System Exit
- Logout functionality

## Technical Stack

- **Backend**: Java Servlets
- **Frontend**: JSP with Tailwind CSS
- **Database**: MySQL
- **Server**: Apache Tomcat
- **Build Tool**: Maven
